# Skeleton Spawners Mod

Enhance skeleton spawners with GUI and loot collection features.

## Features

- GUI for configuring skeleton spawners
- Collect loot when mining skeleton spawners

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft a skeleton spawner using bones.
2. Right-click the skeleton spawner to open the GUI and configure it.
3. Mine the skeleton spawner to collect loot.

## Configuration

The mod does not have a configuration file. All settings are configured through the in-game GUI.
